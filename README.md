# Web_Crawling 프로젝트

웹 크롤링을 활용해 다양한 SNS 및 쇼핑 플랫폼의 데이터를 수집하여, 정리하는 포트폴리오입니다.
각 노트북은 웹 페이지에서 데이터를 수집해 텍스트, CSV, Excel, 이미지, MySQL 저장까지 진행하도록 구성되어 있습니다.

---

## # 프로젝트 구성

### 1) 네이버스토어_베스트.ipynb

- 대상: 네이버 쇼핑 베스트 상품 페이지
- 수집 내용:
  - 판매 순위
  - 업체명
  - 제품명
  - 원가
  - 현재 판매가
  - 할인율
  - 리뷰 수
  - 평점
  - 제품 URL
  - 제품 이미지
- 처리 결과:
  - `.txt` 파일로 수집 내용 저장
  - `.csv`, `.xlsx`로 정리 저장
  - 이미지 파일을 별도 폴더에 저장
  - MySQL 테이블로 import 가능

### 2) 유튜브쇼츠_댓글수집.ipynb

- 대상: 유튜브 쇼츠 댓글 페이지
- 수집 내용:
  - 작성자 ID
  - 작성일자
  - 댓글 내용
  - 좋아요 수
- 처리 결과:
  - `.txt` 로그 파일 저장
  - `.csv`, `.xlsx` 정리본 생성
  - MySQL 테이블로 import 가능

### 3) 인스타_이미지수집.ipynb

- 대상: 인스타그램 해시태그 검색 결과
- 수집 내용:
  - 해시태그 기반 게시물 URL
  - 대표 이미지 다운로드
  - 게시물 해시태그 목록
- 처리 결과:
  - `.csv`, `.xlsx` 저장
  - 이미지 파일 저장
  - MySQL import 코드 포함

## # 주요 기술 스택

- Python
- Selenium
- BeautifulSoup
- Pandas
- MySQL

---

## # 수집 흐름

1. ChromeDriver 실행
2. 대상 웹사이트 접속
3. 페이지 스크롤 또는 동적 로딩 반영
4. HTML 파싱
5. 필요한 필드 추출
6. 텍스트/CSV/Excel 형식으로 저장
7. 이미지 다운로드
8. MySQL DB import (선택)

---

## # 생성되는 결과물

- `.txt` : 수집 로그 및 원본 정보 저장
- `.csv` : 표형 데이터 저장
- `.xlsx` : Excel 형식 저장
- `images/` : 이미지 파일 저장 폴더
